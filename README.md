# ТехМастер — лендинг сервиса по ремонту смартфонов

Одностраничный сайт-визитка для сервиса по ремонту телефонов и планшетов. Проект выполнен на чистом HTML, CSS и JavaScript без фреймворков, сборщиков и зависимостей.

Сайт подходит для локального запуска, демонстрации заказчику и дальнейшей публикации на продакшн-хостинге.

## Что входит в проект

- лендинг с секциями: hero, услуги, преимущества, отзывы, прайс, форма, контакты, карта;
- адаптивная вёрстка под мобильные и десктоп;
- динамическая загрузка прайса из Google Sheets с кэшем в localStorage;
- форма заявки через iframe Яндекс Форм;
- резервный fallback при недоступности формы и Google Sheets;
- лёгкая структура без сборки и зависимостей.

## Технологии

- HTML5
- CSS3
- Vanilla JavaScript
- Google Sheets Visualization API
- Yandex Forms iframe

## Как запустить локально

Для проверки проекта достаточно поднять обычный статический сервер:

```bash
python -m http.server 5173
```

После этого откройте в браузере:

```text
http://localhost:5173
```

Важно: открывать `index.html` напрямую через `file://` можно только для визуальной проверки. Для корректной работы формы и прайса нужен http(s)-адрес, так как браузер блокирует запросы к Google Sheets и Яндекс Формам в режиме локального файла.

## Прайс из Google Sheets

Проект умеет загружать цены из таблицы Google Sheets по API.

### Используемые параметры

- Таблица: `17XcjqC2wzKik1McpANL5uvX2kKLhWzUf0DO-k_ZnZ-c`
- Лист: `Цены на ремонт`
- Колонки: `Устройство | Услуга | Цена`

### Поведение

- данные загружаются через Google Visualization API;
- результат сохраняется в `localStorage` на 1 час;
- если Google недоступен, сайт показывает кэшированные данные или статичный fallback;
- при отсутствии данных от Google выводится сообщение: «Цены уточняйте по телефону».

Если структура таблицы изменится, проверьте функцию `parseResponse()` в файле `js/prices.js`.

## Форма заявки

Форма подключена через iframe Яндекс Форм:

```html
<iframe src="https://forms.yandex.ru/u/..." ...></iframe>
```

Если форма не загрузилась в течение 12 секунд, сайт автоматически показывает резервный блок с кнопкой «Открыть форму в новой вкладке», телефоном и Telegram.

## Что нужно заменить перед публикацией

Перед запуском сайта в продакшн обновите следующие данные:

- название сервиса (`ТехМастер`);
- город и адрес;
- телефон;
- Telegram;
- реквизиты компании;
- ссылку на политику конфиденциальности;
- отзывы;
- карту;
- фотографии;
- актуальные ссылки на `tel:`, `mailto:` и карты.

В проекте placeholders уже отмечены как:

- `[Город]`
- `[Улица]`
- `[Дом]`
- `+7 (XXX) XXX-XX-XX`
- `@login_servisa`
- `ИП/ООО [Название]`
- `ИНН [Номер]`

- ссылку на эту страницу из футера и шапки;

## Деплой

Сайт представляет собой статический проект, поэтому его можно разместить на любом хостинге, поддерживающем обычные HTML/CSS/JS файлы, например:

- GitHub Pages
- Netlify
- Vercel
- обычный VPS/хостинг

Для продакшна рекомендуется проверить:

- корректность мета-тегов и Open Graph;
- рабочую ссылку на политику;
- актуальный номер телефона и адрес;
- загрузку прайса из Google Sheets;
- работоспособность формы на реальном домене.
