# ТехМастер — лендинг сервиса по ремонту смартфонов

Одностраничный сайт-визитка на чистом HTML5 / CSS3 / Vanilla JS.
Без CMS, фреймворков, сборщиков и внешних библиотек.

> **Демо-кейс.** Проект учебный: контакты, реквизиты и цены — заглушки.
> Перед публикацией замените данные из списка ниже.

## Структура проекта

```
index.html          — лендинг
privacy.html        — политика конфиденциальности (шаблон под 152-ФЗ)
css/style.css       — все стили
js/prices.js        — загрузка прайса из Google Sheets + кэш + fallback
js/main.js          — меню, анимации появления, липкая панель, iframe
assets/favicon.svg  — иконка сайта
assets/hero-photo-640.webp — герой-фото для мобильных
assets/hero-photo-960.webp — герой-фото для десктопа
```

## Как запустить локально

Для полноценной проверки поднимите простой сервер:

```bash
python -m http.server 5173
```

и перейдите на `http://localhost:5173`. Открывать `index.html` напрямую через `file://`
можно только для визуальной проверки: форма и прайс в этом режиме ограничены браузером.

Для проверки загрузки прайса и формы нужен http(s)-адрес: при открытии через `file://`
браузер блокирует запросы к Google и может не показать iframe Яндекс Формы.
В этом случае сайт не ломается: прайс берётся из статичного снимка, а вместо формы
появляется блок с кнопкой «Открыть форму в новой вкладке» и контактами.

## Прайс из Google Sheets

- Таблица: `17XcjqC2wzKik1McpANL5uvX2kKLhWzUf0DO-k_ZnZ-c`
- Лист: `Цены на ремонт`
- Колонки: `Устройство | Услуга | Цена`
- Источник: Google Visualization API (`gviz/tq?tqx=out:json`) — JSON отдаёт CORS,
  публиковать лист через «Поделиться в интернете» не требуется, достаточно доступа по ссылке.
- Кэш: `localStorage`, ключ `tehmaster:prices:v1`, TTL — 1 час.
  Если данные в таблице изменились, посетитель увидит их после истечения кэша
  или после очистки хранилища браузера.
- Если Google недоступен:
  - при наличии кэша показываются последние загруженные цены и пометка «Не удалось обновить прайс»;
  - без кэша показывается статичная таблица-снимок из `index.html` и сообщение
    «Цены уточняйте по телефону».

### Как менять цены

Меняйте только таблицу — сайт подтянет изменения сам. Названия устройств и услуг
пишите как есть; группировка по устройству выполняется автоматически.
Порядок строк сохраняется, поэтому блоки удобно держать рядом.

Если структура прайса изменится (добавите колонки или лист), поправьте
`parseResponse()` в `js/prices.js`.

## Форма заявки

Встроена через iframe Яндекс Формы:

```html
<iframe src="https://forms.yandex.ru/u/6adb26714a052da37d5cf63d?iframe=1" ...></iframe>
```

- Уведомления, маска телефона и чекбокс согласия настраиваются в конструкторе Яндекс Форм.
- `embed.js` автоматически подгоняет высоту iframe под содержимое.
- Стилизовать содержимое iframe нельзя — только контейнер. Цвет кнопки «Отправить»
  и тема формы задаются в настройках самой формы (сейчас кнопка синяя, цвет бренда
  можно поменять в Яндекс Формах на акцентный `#ED5A1C`).
- Если форма не прислала `postMessage` о загрузке за 12 секунд, `js/main.js` показывает
  брендированный fallback: кнопку открытия формы в новой вкладке, телефон и Telegram.
  При этом iframe скрывается, а не остаётся серым прямоугольником.
- Рядом с формой всегда есть ссылка «Открыть в новой вкладке» — на случай блокировщиков
  и строгих настроек приватности.
- После публикации проверьте форму по реальному домену: при `file://` сообщение об ошибке
  ожидаемо из-за ограничений origin/CORS.

## Технические заметки

- **Адаптив:** 320 / 375 / 768 / 1024 / 1440 px. Таблица прайса на мобильных
  остаётся двухколоночной, группы устройств — заголовками.
- **Шрифты:** системный стек, внешних шрифтов нет (быстрый LCP, нет FOUT).
- **Палитра:** вариант A «Тёплый янтарь» — кремовый и персиковый фон, лавандовые акценты,
  эспрессо-блоки и янтарные градиенты. Токены заданы в `:root`, тёмные секции
  переопределяются локально.
- **Анимации:** `IntersectionObserver`, подчёркивание заголовков, блик на кнопках,
  мягкий подъём карточек и фото; всё отключается при `prefers-reduced-motion`.
- **Доступность:** семантические секции, `h1–h3`, skip-link, `aria` у меню,
  `title` у iframe, контраст текста, видимый фокус.
- **SEO:** title, description, Open Graph, `alt` у изображения, `lang="ru"`.
- **Производительность:** один внешний CSS и два небольших JS-файла,
  iframe грузится лениво, фото — локальные WebP 640/960 px с `srcset`.
  Исходник `assets/Photo.bmp` обрезан в 4:3 с правым якорем и сконвертирован
  в WebP (25 и 38 КБ); при ошибке загрузки остаётся SVG-подложка без внешних запросов.
- **Демо-метка:** «Демо-кейс» выведена в подвале `index.html` и `privacy.html`.

## Проверка перед сдачей

1. Открыть сайт на 320, 375, 768 и 1440 px; проверить, что бейджи под фото
   не перекрывают подпись и не выходят за карточку.
2. Убедиться, что прайс загрузился и совпадает с таблицей.
3. Проверить fallback прайса: заблокировать `docs.google.com` в DevTools → Network
   и перезагрузить страницу (кэш предварительно очистить).
4. Отправить тестовую заявку через форму и проверить уведомление.
5. Проверить fallback формы: открыть сайт через `file://` или заблокировать
   `forms.yandex.ru` — через 12 секунд должен появиться блок с новой вкладкой.
6. Проверить `tel:`-ссылки на телефоне и переход в Telegram.
7. Прогнать Lighthouse (Performance / Accessibility / Best Practices / SEO).
